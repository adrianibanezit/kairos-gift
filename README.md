# Kairos Visuals · Vale regalo

Landing page estática, sin dependencias, pensada para publicar directamente en GitHub Pages o Vercel.

## Publicar en Vercel
1. Sube esta carpeta a un repositorio de GitHub.
2. En Vercel, importa el repositorio.
3. No necesitas configurar build command ni variables de entorno.
4. Vercel publicará `index.html` automáticamente.

## Personalización
- `index.html`: textos y contenido.
- `styles.css`: colores, tamaños y responsive.
- `script.js`: animación de confeti.
- `logo.png`: logo preparado a partir del archivo proporcionado.
